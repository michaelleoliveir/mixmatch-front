# 🎵 Mix&Match

Mix&Match is a full-stack web application that combines **Google Gemini AI** with the **Spotify Web API** to create personalized music experiences — and lets you discover how compatible your music taste is with your friends.

## ✨ Features

- **AI Playlist Creator**: Describe your mood or vibe and get a curated track list generated by Gemini AI, ready to save directly to Spotify.
- **Mix & Match Hub**: Share a unique link with friends to compare your listening history and get a compatibility score.
- **Match History**: View all past matches, ranked by compatibility score, with date and friend info.
- **Match Detail**: Dive into a specific match to see the artists and tracks you both have in common.
- **Spotify Integration**: Full OAuth2 authentication and direct playlist creation in your library.
- **Responsive UI**: Sidebar navigation on desktop, bottom nav on mobile, with skeleton loading states throughout.

## 🚀 Tech Stack

### Frontend
- **React + Vite**: Core framework for a fast SPA.
- **Tailwind CSS**: Utility-first styling with glassmorphism design system.
- **Framer Motion**: Animations for transitions, staggered lists, and the score ring.
- **shadcn/ui**: Component library (Button, Input, Skeleton, etc.).
- **React Router v6**: Client-side routing.
- **Lucide React**: Icons.

### Backend (API)
- **Laravel**: PHP framework handling API logic, auth, and service architecture.
- **Google Gemini API**: Generative AI for music curation.
- **Spotify Web API**: Music data, user profile, and library management.

## 📄 Pages

| Route | Description |
|---|---|
| `/` | Landing / login |
| `/dashboard` | Top tracks and artists from your Spotify |
| `/create-playlist` | AI playlist generator |
| `/match` | Mix & Match Hub — share link and match history |
| `/match/:matchCode` | Match result when a friend opens your link |
| `/match/detail/:id` | Detailed view of a specific past match |

## 🪝 Custom Hooks

| Hook | Responsibility |
|---|---|
| `useAuth` | Spotify OAuth flow and session management |
| `useLoadData` | Fetches top tracks and artists for the dashboard |
| `useMatch` | Generates the share link and fetches match result data |
| `useRanking` | Fetches match history list and individual match details |

## 🛠️ Getting Started

### Prerequisites
- Node.js & npm
- PHP 8.2+ & Composer
- Spotify Developer Account (Client ID and Secret)
- Google Cloud Console (Gemini API Key)

### Installation

1. **Clone the repository**:
    ```bash
    git clone https://github.com/michaelleoliveir/mixmatch-front.git
    cd mixmatch-front
    ```

2. **Install dependencies**:
    ```bash
    npm install
    ```

3. **Setup environment variables**:
    Create a `.env` file in the root:
    ```env
    VITE_BACKEND_API=http://localhost:8000/api
    ```

4. **Run the development server**:
    ```bash
    npm run dev
    ```

> Make sure the [Mix&Match Backend](https://github.com/michaelleoliveir/mixmatch-api) is also running.
